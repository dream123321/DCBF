# DCBF Update - 2026-11-09

## 中文

- 新增 SUS2-SH CPU 发行版 `v3-sus2sh-20261109-ase-abacus`，基于 DCBF v3-20261003。
- 采样描述符按 SUS2-SH 模型 metadata 的 `sh_scalar_info` 动态分组二／三／四／五／六体；采样默认使用二体和三体，四体及以上需显式配置 `body_list`。
- 采样低内存路径：分片 CFG/out、受限并行解析、body 释放、partwise 选择与同模型覆盖融合，保持帧顺序和选择规则。
- Reduce 新增 `update_model_after_selection` 和 `run_scf_labeling`，按每轮实测覆盖率选择阶段预算并在最终覆盖目标停止；支持 checkpoint 接续和 transactional resume。
- 初始 MD 使用 `pysuperlinear.SuperlinearCalculator`；SUS2-SH CPU 后续 MD 使用 `sus2/embedded`。
- VASP POTCAR 匹配改为精确元素路径并校验 `TITEL`，避免 C 误匹配 Cu 等前缀歧义。
- 保留 `candidate_only` / `reference_guided`、逐维最小覆盖、全局反向去冗余和候选池逻辑。

## English

- Adds the SUS2-SH CPU distribution `v3-sus2sh-20261109-ase-abacus`, based on DCBF v3-20261003.
- Sampling descriptor bodies are grouped dynamically from SUS2-SH model metadata (`sh_scalar_info`); sampling defaults to two/three-body and requires an explicit `body_list` for four and higher.
- Low-memory sampling: sharded CFG/out, bounded parallel parsing, body release, partwise selection, and same-model coverage fusion while preserving frame order and selection rules.
- Reduce adds `update_model_after_selection` and `run_scf_labeling` with per-round measured-coverage stage budgets, final-target stopping, checkpoint continuation, and transactional resume.
- Initial MD uses `pysuperlinear.SuperlinearCalculator`; subsequent SUS2-SH CPU MD uses `sus2/embedded`.
- VASP POTCAR lookup now uses exact element paths with `TITEL` validation, preventing prefix ambiguities such as C vs Cu.
- `candidate_only` / `reference_guided`, per-dimension minimum cover, global reverse pruning, and candidate-pool behavior are retained.
